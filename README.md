# LookLab - Projeto Desenvolvimento Front-End para Web
LookLab - O seu laboratório fashion!   

O LookLab é uma aplicação web de closet de roupas virtual com foco em interatividade, permitindo que o usuário não apenas visualize peças, mas também monte seus próprios looks de forma dinâmica e intuitiva.  

O projeto foi desenvolvido como parte da disciplina de Desenvolvimento Front-End para Web, com o objetivo de aplicar conceitos fundamentais de construção de interfaces modernas, organização de componentes e experiência do usuário.

Funcionalidades
* Visualização de peças de roupa em formato de catálogo
* Filtros por categoria, cor e estilo
* Montagem de looks personalizados
* Adição e remoção de peças em tempo real
* Salvamento de combinações (armazenamento local)
* Interface responsiva para diferentes dispositivos

Linguagens Utilizadas
* HTML5
* CSS3 
* JavaScript

Objetivo
O principal objetivo do projeto é demonstrar a construção de uma aplicação front-end funcional, com foco em usabilidade, organização visual e manipulação de estado, simulando uma experiência próxima a aplicativos reais de moda.

Possíveis Melhorias Futuras
* Sistema de login e perfis de usuário
* Integração com banco de dados
* Sugestões automáticas de looks
* Funcionalidade de arrastar e soltar (drag and drop)
* Integração com APIs de moda ou e-commerce


Este projeto representa a aplicação prática de conceitos de desenvolvimento front-end, com ênfase em interatividade e experiência do usuário.
